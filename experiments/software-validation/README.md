# Software-validation evidence

This directory preserves machine-readable outputs for the deterministic software-validation claims in the Caleta preprint. Files from GitHub runners are downloaded from CI artifacts; they are not written as simulated results from another operating system.

## Commands

Run locally:

```bash
cargo build --locked
python3 tests/record_validation.py \
  --output-dir experiments/software-validation/results/windows-local \
  --runner-os windows-local
```

Aggregate hosted results after downloading CI artifacts:

```bash
python3 tests/aggregate_validation.py \
  experiments/software-validation/results/ubuntu-latest \
  experiments/software-validation/results/macos-latest \
  experiments/software-validation/results/windows-latest \
  --expected-os 3 \
  --local-dir experiments/software-validation/results/windows-latest \
  --output experiments/software-validation/results/table1-software-validation.json
```

## Claim mapping

| Paper claim | Evidence |
|---|---|
| 15 unit tests passed, zero failed | `results/<runner>/unit_tests.json` and `cargo-test.log`; aggregated in `table1-software-validation.json` |
| 45-byte deterministic artifact | `results/<runner>/mock-e2e.json`, generated by `tests/e2e_mock.py` from `model.stat().st_size` |
| Two successful mock benchmark runs, zero failed | `results/<runner>/mock-e2e.json` and the benchmark command in `tests/e2e_mock.py` |
| Hosted validation on Ubuntu, macOS and Windows | Three runner directories and `table1-software-validation.json` |
| Graceful or forced mock shutdown | `shutdown` and `execution_record_validated` in each `mock-e2e.json` |

The aggregator refuses missing runner directories and failed validations. Local-only aggregation may use `--expected-os 1` during development, but the public hosted claim requires all three named CI runner directories.
