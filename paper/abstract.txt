Local large language model (LLM) inference is frequently described as private, verified, or reproducible without separating the technical claims behind those terms. A local deployment can still execute an unintended artifact, inherit unsafe configuration, expose unnecessary API routes, or publish aggregate performance results that omit failed runs and methodological differences. This paper presents Caleta, an Apache-2.0 process supervisor and evidence layer around llama.cpp rather than a new inference engine. Caleta combines versioned model manifests, exact-size and SHA-256 verification, controlled backend construction, a restricted OpenAI-compatible proxy, prompt-free execution records, reproducible benchmark reports, and a small conformance suite. Its research contribution is the composition of these mechanisms into explicit, machine-readable contracts that distinguish integrity from authenticated provenance and privacy controls from operating-system isolation. We evaluate the reference implementation through strict static checks, fifteen unit tests, and a deterministic end-to-end experiment covering verification, process supervision, authentication, model listing, server-sent events, conformance, and benchmarking. The experiment validates software behavior, not model accuracy, inference throughput, or llama.cpp compatibility with real GGUF artifacts. We therefore present no real-model performance claim. The resulting design offers a reproducible foundation for studying trustworthy local inference while making the remaining threats--unsigned manifests, time-of-check/time-of-use replacement, lack of TLS and OS-enforced egress isolation, and incomplete API conformance--explicit subjects for future work.
